## 裁決:主軸 A/B 融合,核心問題重寫

1. **聚合層(pass@1)**:Q4 與高精度無顯著差(vs FP16 −0.77pp p=0.95;vs Q8 −3.9pp)
   → 原主軸 A 前提「Q4 有聚合損失待補償」不成立,與 arXiv 2503.07103 一致。
2. **分佈層**:損傷真實存在但住在別處——pass@5 差 19.2pp(Q8−Q4)、
   解集 Jaccard 僅 0.667(FP16 vs Q4)/0.786(FP16 vs Q8)
   → 主軸 B 的解集位移儀器(JCR,arXiv 2606.27205)證實是對的量尺。
3. **邊界形狀**:3B 的量化懸崖在 Q4|Q3 之間(27.7%→0%,結構性總崩潰;
   Q3 連 module 關鍵字都丟失,Q2 為 token 沙拉,對照測試證實非 Verilog 特有)
   → 與 34B 級文獻的 2–3bit 漸進退化質性不同:**小模型沒有退化緩衝,只有懸崖**。
4. **系統層(計畫外)**:Q8 嚴格支配 FP16——品質 +4.62pp(CI[−7.69,−1.54],p=0.03)
   且速度 2 倍 → 記憶體受限政體下「更高精度=更差」;候選解釋為溢出數值路徑,待複驗。
5. **重寫的核心研究問題(H3″)**:量化損傷的形態是「可搶救區縮小」
   (部分通過題:Q8=10、Q4=5)而閉環修復恰好以可搶救區為工作空間
   → 閉環能否恢復量化造成的解集覆蓋損失?這是四篇最近鄰與量化文獻都未觸及的交互。
